
Module 1: React Hooks Foundations – Week-by-Week Breakdown

📅 Week 1: Core Hooks Deep Dive

🎯 Goals:

- Understand why hooks replaced class components
- Master `useState`, `useEffect`, and `useRef`

📘 Topics:

- `useState`: State initialization, updates, batching
- `useEffect`: Lifecycle mimicry, cleanup functions, dependency arrays
- `useRef`: DOM access, persistent values across renders

🛠️ Exercises:

- Build a **counter app** with `useState`
- Create a **timer app** using `useEffect` and cleanup
- Use `useRef` to **focus an input field** on load

📅 Week 2: Performance-Oriented Hooks

🎯 Goals:

- Optimize rendering and avoid unnecessary re-renders

📘 Topics:

- `useMemo`: Memoize expensive calculations
- `useCallback`: Stable function references for child components
- `React.memo`: Component-level memoization

🛠️ Exercises:

- Build a **search filter app** using `useMemo`
- Create a **list with child components** using `useCallback` and `React.memo`

📅 Week 3: Hook Rules & Debugging

🎯 Goals:

- Internalize hook rules and learn debugging strategies

📘 Topics:

- Rules of Hooks: Top-level calls, only in function components
- Common mistakes: stale closures, missing dependencies
- Debugging: React DevTools, console tracing

🛠️ Exercises:

- Refactor a class component to use hooks
- Break and fix common hook mistakes intentionally

📅 Week 4: Architect’s Perspective

🎯 Goals:

- Learn how hooks fit into scalable architecture

📘 Topics:

- When to use hooks vs custom logic
- Hook-based separation of concerns
- Hook composition patterns

🛠️ Exercises:

- Build a **modular form system** using custom hooks
- Create a **hook library** for reusable logic (e.g., useFetch, useToggle)
